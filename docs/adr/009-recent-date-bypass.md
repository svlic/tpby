# ADR-009：最近 180 天日期 code 直接旁路到 DEAL1

- 状态：已接受（已实现）
- 决策时间：约 2026-09-27
- 相关提交：`0fdf085`、`6ac39dc`

## 背景

输入中的独立六位数字通常是业务 code，但也可能是 `YYMMDD` 日期。对近期日期执行普通 SOURCE 搜索会引入过多无关结果。

## 决策

- 六位数字能够解析为 2000–2099 年的合法 `YYMMDD`，且日期位于上海时区“今天”至过去 180 天（含边界）时，视为日期旁路。
- 日期旁路不搜索 SOURCE，直接将 CODE 消息原生 forward 到 DEAL1。
- 旁路结果写入 `bypasses`，防止重复处理。
- 超出窗口、未来日期或非法日期继续按普通 code 处理。

## 实现

`is_recent_date_code()` 使用 `today - timedelta(days=180)` 计算包含首尾的判断边界。测试使用 2026-03-31 和 2026-03-30 区分固定 180 天与旧日历月算法。

## 结果

- 减少日期数字造成的宽泛 SOURCE 搜索和错误召回。
- 两位年份被明确限定在 2000–2099。
- 判断依赖 Asia/Shanghai 的自然日边界。

## 证据与边界

- **事实：** 日期旁路和 bypass 持久化已实现。
- **事实：** 维护者确认固定 180 天、Asia/Shanghai 和 2000–2099 年解释。
- **事实：** 当前实现和边界测试已经按固定 180 天对齐。
